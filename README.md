# container-image-security-scanning

Build a hardened container image and scan it for vulnerabilities in CI.

> Personal lab project. Built in my own AWS, Azure and GitHub accounts for learning and practice. It is not work I did for any employer or client. Any secrets, keys or tokens shown in test data are fake.

## What this builds

A small non root image, a vulnerability scan that fails the build above a chosen severity, and a report of what was fixed and what was accepted.
